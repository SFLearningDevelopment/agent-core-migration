AgentCore Migration Lab / Tier 1 Foundational

Tier 1 — Off the Starter Toolkit, onto the AgentCore CLI

Before you can build anything the new way, you need the new tool installed and the old one out of the way. This tier is short but it removes a trap that breaks later commands.

The situation

The Bedrock AgentCore Starter Toolkit was a Python CLI (installed with pip install bedrock-agentcore-starter-toolkit). It is now legacy and no longer supported. The AgentCore CLI, published as the npm package @aws/agentcore, replaces it.

Both expose the same command name — agentcore. If the old toolkit is still installed when you add the new CLI, the two collide and you can end up running commands against the wrong tool. So the first job in any migration is a clean uninstall.

Primer: what actually changed, and what didn't

What changed is the developer tooling and its language runtime: Python toolkit → Node.js CLI. What did not change is the platform underneath. Amazon Bedrock AgentCore — its Runtime, Memory, Gateway, Identity and Observability services — is still the destination. You are swapping the tool that scaffolds and deploys, not the thing you deploy to.

Keep those two layers separate in your head. Exam questions often test whether you can tell "the CLI changed" apart from "the runtime changed."

Prerequisites

RequirementWhy
Node.js 20+The AgentCore CLI ships as an npm package.
Python 3.10+The generated agent code is Python.
AWS CDKThe CLI uses CDK to provision AWS resources on deploy.
AWS credentialsConfigured via aws configure, in a supported region.
Note the split

Node.js runs the CLI; Python runs the agent it generates. Needing both is expected, not a mistake.

Do it

Step 1 · Remove the legacy toolkit

Uninstall with whichever installer you originally used:

pip uninstall bedrock-agentcore-starter-toolkit     # installed via pip
pipx uninstall bedrock-agentcore-starter-toolkit   # installed via pipx
uv tool uninstall bedrock-agentcore-starter-toolkit # installed via uv

If you're not sure how it was installed, checking all three is harmless.

Step 2 · Install the AgentCore CLI
npm install -g @aws/agentcore

If the old Python CLI is still present, the installer prints a warning asking you to uninstall it — that warning is your signal that Step 1 didn't fully take.

Step 3 · Confirm the new CLI answers
agentcore --help

You should see the AgentCore CLI's commands (create, dev, deploy, invoke, add, remove). If you instead see Python-toolkit output, the old command is still shadowing the new one — go back to Step 1.

Check your understanding
