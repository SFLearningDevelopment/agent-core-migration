Migrating to Amazon Bedrock AgentCore

A hands-on lab. You will retire the old Starter Toolkit workflow, build and deploy an agent with the AgentCore CLI, and map a Bedrock Agents Classic configuration onto AgentCore. Leads to the SF Certified AgentCore Migration Practitioner certification.

AWS AI certification prep AgentCore CLI Bedrock Agents Classic ~90 min

Why this lab exists

Two AWS changes landed close together, and AI certification questions now assume you know both.

First, the Python-based Bedrock AgentCore Starter Toolkit is no longer supported. The Node.js AgentCore CLI (@aws/agentcore) is its successor for creating, developing, and deploying agents. Second, the original Amazon Bedrock Agents service — now called Bedrock Agents Classic — entered maintenance mode and closes to new customers on July 30, 2026. AWS recommends migrating those workloads to AgentCore.

Put together: the tool you use to build changed, and the service you build on changed. This lab walks both, in the order an exam candidate needs to reason about them.

Read this first

"Classic in maintenance mode" is not the same as "deleted." Existing Bedrock Agents Classic keep running; the service is closed to new agents for accounts without prior use. Exam distractors lean on this distinction — answer for maintenance mode, not removal.
